# Mein Schießbuch – iPhone-PWA v1.2.1

- Kleinster Teiler wurde in das freie sechste Feld des Statistikrasters verschoben, rechts neben „Beste 10-Schuss-Serie“.
- Akzentfarbe bleibt separat einstellbar und wird nun auch für Diagrammlinien und -punkte verwendet.
- Neue Einstellung „Hintergrundfarbe“ mit frei wählbarem Farbwert. Sie ändert den gesamten Seitenhintergrund der App; Karten behalten ihr dunkles Karten-Design.
- Name, Akzentfarbe, Hintergrundfarbe und LG-40-ZR-Freischaltung werden lokal gespeichert.
- Service-Worker-Cache auf Version 1.2.1 erhöht, damit das Update geladen wird.
